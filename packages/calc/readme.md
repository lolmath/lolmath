# Calc

A collection of functions for calculating League of Legends stats.

## Installation

```bash
npm install @lolmath/calc
```

## Stubs

The package covers every mechanic in the game, but most of them are still
declared rather than implemented. A stub has the same signature and the same
documentation as the finished function will have, and its documentation carries
a `@throws Not implemented.` line. Calling one throws instead of returning a
wrong number.
