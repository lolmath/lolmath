# Colors

Every color in `@lolmath/ui` is a CSS custom property named `--lol-color-<family>-<shade>`,
exposed to Tailwind as `lol-<family>-<shade>` (e.g. `bg-lol-grey-400`). There is no
semantic layer on top — no `--surface`, no `--card` — so picking the right token
means knowing what each shade is *for*, not just what it looks like. That's what
this page is for.

The palette has four families: **blue** (the hextech current), **grey**
(neutral surfaces and secondary text), **gold** (metal linework and ink), and a
single **hextech black**. Within a family, the shade number tracks how far the
color sits from where it started — it isn't a strict lightness ramp, so always
check the swatch rather than assuming.

it's the one color you should reach for first when something needs to look like
the base layer rather than a layer above it.

That ordering is also the one to reach for when stacking surfaces: `hextech-black`
for the page, `grey-400` for a card or panel resting on it, `grey-300` for the
moment someone interacts with something inside that card. Keeping those three
distinct is what lets a hover state still read as "reacting" once it's sitting
on a card background instead of directly on the page.

Blue is spent almost entirely on the primary button's energy — it's a gradient,
not a set of flat fills, so 100–500 only make sense as the five stops of
"resting → hover → pressed". Reach for 600/700 when you need a dark, faintly
blue panel backdrop rather than a neutral one (that's what the chart frame
does); reach for grey when you just need "dark and quiet."

Gold is ink and metal, never a background — see "Charts / The Hextech
language" for the fuller argument, made for charts but true everywhere: gold
*frames* and *labels* content, it doesn't sit behind it.

## Picking a background

| You're building | Use |
| --- | --- |
| The page itself | `hextech-black` |
| A recessed field — text input, dropdown, open listbox | `hextech-black` |
| A static elevated surface — a card, a panel | `grey-400` |
| A hover, focus or selected state | `grey-300` |
| A disabled field's background — input, stepper button | `grey-300` |
| A disabled button's fill | the `--lol-gradient-disabled` gradient (built from `grey-150`), not a flat background |

## Using a token

```css
.card {
	background: var(--lol-color-grey-400);
}
```

```tsx
<div className="bg-lol-grey-400">...</div>
```
