---
title: Node.js
---

We use [Node.js](https://nodejs.org/en/) as runtime environment. The version may
be pinned using .nvmrc.

You can use [fnm](https://github.com/Schniz/fnm) to install node. fnm also
listens to the .nvmrc file and automatically switches to the correct version of
Node.js when you enter a directory.
